# TestFlyQA - Office Management System

A comprehensive office management system for TestFlyQA.

## Features

- 👥 Employee Management
- 💻 Assets Tracking
- 🛒 Procurement Management (6-stage workflow)
- 📦 Inventory Control
- 🗄️ Lockers Management
- ❄️ AC Management
- 🔧 Maintenance Tickets
- 💰 Budget Planning
- 📊 Reports (Excel/PDF export)
- 🎉 Events & Sports
- 📁 Document Management
- 👤 User Management with JWT auth
- 🌐 Bilingual (English + Portuguese)
- 🌙 Dark Mode

## Tech Stack

### Backend
- .NET 10
- Entity Framework Core
- PostgreSQL
- JWT Authentication
- BCrypt Password Hashing

### Frontend
- React 18 + TypeScript
- Vite
- Material-UI (MUI)
- React Router
- i18next
- Axios
